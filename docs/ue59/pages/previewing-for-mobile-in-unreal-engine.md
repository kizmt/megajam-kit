# Previewing for Mobile

https://dev.epicgames.com/documentation/en-us/unreal-engine/previewing-for-mobile-in-unreal-engine?application_version=5.9

> Learn how to preview mobile content from the Unreal Editor.

[image: Previewing for Mobile]

Deploying a full build to a physical device every time you need to playtest can delay your development pipeline. Unreal Engine provides tools to preview and test your mobile content directly from the Editor, without leaving your development environment.

The following documents describe how to simulate mobile platform rendering in-editor and how to test real device input on a physical iOS device over your local network without having to produce builds.

- [image: Mobile Previewer] Mobile PreviewerPreviewing your games inside the Unreal Engine is based on the selected Mobile Platforms. (-> using-the-mobile-previewer-in-unreal-engine)

- [image: Using Remote Session Plugin for iOS Development] Using Remote Session Plugin for iOS DevelopmentReplicate inputs from an iOS device on your PC for testing. (-> using-the-remote-session-plugin-for-ios-development-in-unreal-engine)
