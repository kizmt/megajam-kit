When you are ready and have an understanding of the core aspects behind Blueprints, Gameplay oriented Blueprint Tutorials can be found in Gameplay Systems (-> gameplay-systems-in-unreal-engine) which illustrate gameplay related elements like Spawning / Destroying Actors, Respawning (OnDestroyed), Using Timers, and more.
