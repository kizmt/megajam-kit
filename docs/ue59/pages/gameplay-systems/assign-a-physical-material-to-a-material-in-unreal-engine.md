# Assign a Physical Material to a Material

https://dev.epicgames.com/documentation/en-us/unreal-engine/assign-a-physical-material-to-a-material-in-unreal-engine?application_version=5.9

> Tutorial on how to assign a Physical Material to a Material in Unreal Engine

[image: Assign a Physical Material to a Material]

- Open or create a new **Material**. [image: Open or create a new Material]

- In the **Material Blueprint**, select the main material node. [image: Select the main material node]

- In the **Details** panel, use the Physical Material dropdown to select or create a Physical Material. [image: Use the Physical Material dropdown to select or create a Physical Material]

- Click **Save**.
