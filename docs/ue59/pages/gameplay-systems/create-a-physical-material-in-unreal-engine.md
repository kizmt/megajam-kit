# Create a Physical Material

https://dev.epicgames.com/documentation/en-us/unreal-engine/create-a-physical-material-in-unreal-engine?application_version=5.9

> Tutorial on how to create Physical Material in Unreal Engine

[image: Create a Physical Material]

- From the **Content Drawer**, click **+Add** -> **Physics** -> **Physical Material** or right-click in the **Content Drawer** -> **Physics** -> **Physical Material**. [image: Create Physical Material]

- Select the **Physical Material Class**. [image: Select the Physical Material Class]

- Double-click the new **Physical Material** to open it. [image: Double-click the new Physical Material to open it]

- Adjust the **Properties**. [image: Adjust the Properties]

- Click **Save**.

See the **Physical Material Reference** (-> physical-materials-reference-for-unreal-engine) for information on the properties in the Physical Material.
