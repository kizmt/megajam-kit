# Chaos Visual Debugger

https://dev.epicgames.com/documentation/en-us/unreal-engine/chaos-visual-debugger-in-unreal-engine?application_version=5.9

> Documentation for Chaos Visual Debugger in Unreal Engine.

[image: Chaos Visual Debugger]

**Chaos Visual Debugger **(**CVD**) is an in-editor tool and standalone program that you can use to record Chaos physics (-> physics-in-unreal-engine) simulations and collect state data during runtime.

Using this tool and the data it provides, you can efficiently and collaboratively debug physics simulations for applications running on your machine, as well as from a remote machine, or a platform that’s connected to your machine.

## What’s New in Chaos Visual Debugger 1.2

[image: Chaos Visual Debugger]

Chaos Visual Debugger 1.2 includes the following:

- **The **Standalone Debugger (-> getting-started-with-chaos-visual-debugger)**: ** Build and package CVD as a standalone Unreal Engine program.
- **Improved support for networked physics debugging**:**Multi-source support (-> playback-in-chaos-visual-debugger):** Load two or more separate recordings at once.
- **The Session Discovery System (-> live-debugging-with-chaos-visual-debugger):** Find any locally running server or client build, and start recordings in a single click.

- **Improved performance**: To reduce resource consumption, we overhauled how geometry is generated and how objects are represented under the hood.

For a full overview of the new features, see the CVD section (-> unreal-engine-5-6-release-notes) of the Unreal 5.6 Release Notes.
