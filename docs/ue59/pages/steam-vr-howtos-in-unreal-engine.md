# Steam VR How-Tos

https://dev.epicgames.com/documentation/en-us/unreal-engine/steam-vr-howtos-in-unreal-engine?application_version=5.9

> How-To guides providing step-by-step instructions for working with Steam VR and Unreal Engine.

The Steam VR How-Tos contain step-by-step guides that will walk you through how to use UE and Steam VR together.

- Set Up a Seated Camera for SteamVR (-> set-up-a-seated-camera-for-steamvr-in-unreal-engine): Setting up the Unreal Engine camera to work with a seated SteamVR experience.

- Set Up the SteamVR Input System (-> set-up-the-steamvr-input-system-in-unreal-engine): Setting up Unreal Engine to work with the SteamVR Input system.

- Detect SteamVR Chaperone System Activation (-> detect-steamvr-chaperone-system-activation-in-unreal-engine): Detecting if the user has activated the SteamVR Chaperone system.

- Interact with the SteamVR Chaperone System (-> interact-with-the-steamvr-chaperone-system-in-unreal-engine): Interact with the various components of the SteamVR Chaperone system.

- Set Up a Standing Camera for SteamVR (-> set-up-a-standing-camera-for-steamvr-in-unreal-engine): Setting up the camera to work with a standing SteamVR experience.

- Set Up the SteamVR Chaperone (-> set-up-the-steamvr-chaperone-in-unreal-engine): Setting up the SteamVR Chaperone system in Unreal Engine.
