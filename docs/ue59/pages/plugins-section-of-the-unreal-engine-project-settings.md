https://dev.epicgames.com/documentation/en-us/unreal-engine/plugins-section-of-the-unreal-engine-project-settings?application_version=5.9

> Reference for the Plugins section of the Unreal Engine Project Settings.

[image: Plugins Settings]

This is not an exhaustive list of all plugins whose settings can be configured from the Project Settings window. Enabling and disabling plugins (-> working-with-plugins-in-unreal-engine) can add plugin-specific sections to the Project Settings window. If a plugin's settings don't appear in this section, refer to that plugin's documentation to learn more about the settings it supports.

The **Plugins** section of the Unreal Engine Project Settings window contains the following categories:

- ui
- basics
