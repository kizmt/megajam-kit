# Capture Manager

https://dev.epicgames.com/documentation/en-us/unreal-engine/capture-manager?application_version=5.9

> Learn how to use the Capture Manager layout in Live Link Hub.

**Capture Manager **in Live Link Hub (-> live-link-hub-in-unreal-engine) is used to ingest footage captured on a variety of devices including audio, mono and stereo video, and mobile using the** Live Link Face** application. The footage is referred to as a take.

> **note:** The **Capture Manager Layout** in Live Link Hub replaces the Capture Manager tool that was part of **Unreal Engine**. The original Capture Manager tool will be removed in a future version of Unreal Engine.

- Capture Manager Quick Start (-> capture-manager-quick-start): Get started using Capture Manager in Live Link Hub.

- Capture Manager Devices (-> capture-manager-devices): Understand how to use the devices available in Capture Manager.

- Configuring Capture Manager (-> configuring-capture-manager): Capture Manager can be configured in Live Link Hub and Unreal Engine.

- Python Scripting for Capture Manager (-> python-scripting-for-capture-manager-in-unreal-engine): Use the Python API and example scripts to automate Capture Manager.

- Capture Data Asset (-> capture-data-asset): Overview of the Capture Data asset in Unreal Engine.
