# Capture Manager Devices

https://dev.epicgames.com/documentation/en-us/unreal-engine/capture-manager-devices?application_version=5.9

> Understand how to use the devices available in Capture Manager.

**Capture Manager** provides a number of devices that determine how a take is ingested; **Mono Video**, **Stereo Video**, **Live Link Face**, and **Take Archive**. You should use the correct device for the captured data.

- Mono Video Device (-> mono-video-device): An overview of the Mono Video device provided by Capture Manager.

- Stereo Video Device (-> stereo-video-device): An overview of the Stereo Video device provided by Capture Manager.

- Live Link Face Device (-> live-link-face-device): An overview of the Live Link Face device provided by Capture Manager.

- Take Archive Device (-> take-archive-device): An overview of the Take Archive device provided by Capture Manager.
