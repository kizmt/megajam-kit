> How you can develop for ARCore-supported devices in Unreal Engine

[image: Developing for ARCore]

ARCore is a handheld augmented reality (-> developing-for-handheld-augmented-reality-experiences-in-unreal-engine) platform from Google that is supported in Unreal Engine. This page describes how ARCore is supported in Unreal Engine, and how to set up your environment to develop with ARCore. Refer to Supported XR Devices (-> supported-xr-devices-in-unreal-engine) for the full list of which devices and which SDK versions Unreal Engine supports.

## Developing with the ARCore APIs

To develop for ARCore in Unreal Engine you must set up the following:

- Updated hardware and software. Refer to Android Development Requirements (-> android-development-requirements-for-unreal-engine).
- Codeworks for Android installed.
- Android version 26 or greater installed.
- A supported, configured, and connected handheld Android device.
- **Google ARCore** plugin enabled in your project.

Once you're set up for developing with ARCore, you can use the unique ARCore functionality to develop for your Android devices. Refer to Handheld AR Features (-> developing-for-handheld-augmented-reality-experiences-in-unreal-engine) for what features are supported in Unreal Engine.
