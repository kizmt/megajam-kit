> An overview of the Wevr Virtual Studio (WVS) Plugin and Flows.

[image: Wevr Virtual Studio Integration]

Learn to use this **Beta** feature, but use caution when shipping with it.

Wevr Virtual Studio (WVS) is a cloud platform for teams using Unreal Engine that provides remote team collaboration and out-of-the-box automation services, including builds, renders, and testing.

WVS integrates with Unreal Engine in the following ways:

- Plugin: Provides access to WVS Git-based revision control within the Unreal Engine editor.

- Flows: Units of automation that help you perform common tasks in your Unreal project automatically in the cloud, such as creating and deploying builds, rendering art, and converting data.
