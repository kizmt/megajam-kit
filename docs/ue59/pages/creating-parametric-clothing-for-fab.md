# Creating Parametric Clothing for Fab

https://dev.epicgames.com/documentation/en-us/unreal-engine/creating-parametric-clothing-for-fab?application_version=5.9

> Creating Parametric Clothing for Fab in Unreal Engine.

[image: Creating Parametric Clothing for Fab]

Produced by the Parametric Body System introduced in Unreal Engine 5.6, parametric bodies are continuously adjustable within the constraints imposed by the database. In comparison, MetaHuman Creator in the Cloud only allows users to select one of 18 fixed body archetypes.

For a complete guide on creating clothing for the Parametric Body System, see the Creating Parametric Clothing tutorial in the MetaHuman Documentation.
