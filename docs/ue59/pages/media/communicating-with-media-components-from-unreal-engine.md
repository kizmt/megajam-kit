# Communicating with Media Components

https://dev.epicgames.com/documentation/en-us/unreal-engine/communicating-with-media-components-from-unreal-engine?application_version=5.9

> How to communicate with multiple computers and devices.

- DMX (-> dmx-in-unreal-engine): The DMX Plugin enables Unreal Engine use for live events and permanent digital installations.

- Switchboard (-> switchboard-in-unreal-engine): Control multiple remote machines from one application with Switchboard.

- Stage Monitor (-> stage-monitor-with-unreal-engine): Stage Monitor reports events from multiple instances of Unreal Engine

- Timed Data Monitor (-> timed-data-monitor-in-unreal-engine): Monitor, calibrate, and view incoming timed data from multiple sources through Live Link or SDI.
