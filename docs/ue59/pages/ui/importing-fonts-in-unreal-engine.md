# Importing Fonts

https://dev.epicgames.com/documentation/en-us/unreal-engine/importing-fonts-in-unreal-engine?application_version=5.9

> Explains how to import your Font assets for use in your project.

[image: Importing Fonts]

In this guide, you'll learn how to import your own Font files into **Unreal Engine**.

 [image: Banner Image]

When you start to import your Fonts, you can choose between several methods and choose the method that best fits your workflow. The available methods you can use to import are:

- Using the Content Browser's Import button

- Drag-and-drop method into the Content Browser

- Using the Font Editor

You also have the choice between **TrueType Font** (`TTF`) and **OpenType Font** (`OTF`) files when importing your fonts. Choose the import method and font type that best fits your needs.

For this how-to guide, we are using the **Blank Template** project, using no **Starter Content**, with default **Target Hardware** and **Project Settings**.

## Using the Content Browser

You can use the Content Browser's **Import** button to select your `TTF` or `OTF` font file.

- In the Content Browser, click the **Import** button. [image: Click the Import button in the Content Browser]

- After the **Import** dialog window appears, navigate to the `TFF` or `OTF` font file you want to import and select it. Then, click **Open**. [image: Select Font in the Import dialog window]

- After a moment, the **Font Face Import Options** dialog will appear. Select **Yes** from the options listed to create your Font Face asset and your Composite Font asset in your Content Browser. [image: Select Yes in the Font Face Import Options dialog window]

- The Font Face asset can now be found in your folder hierarchy. [image: The imported Font Face asset in folder]

## Using Drag-and-drop

You can **Drag-and-drop** a `TTF` or `OTF` file directly into the Content Browser to create your font assets.

- Navigate to the folder where you've stored your `TTF` or `OTF` file(s) in the **File Explorer**. Drag the file into the **Content Browser** to start the import process. [image: Drag the file into the Content Browser]

- After a moment, the **Font Import Options** will appear. Select **Yes** from the options listed to create your Font Face asset and your Composite Font asset in your Content Browser. [image: Select Yes in the Font Face Import Options dialog window]

- The Font Face asset can now be found in your folder hierarchy. [image: The imported Font Face asset in folder]

## Using the Font Editor

You can import and create Font Face assets directly from the Default Font Family (-> font-asset-and-editor-in-unreal-engine) list in the **Font Editor** removing the need to
import a font asset first then assign it.

- Open an existing **Font** asset or create a new one using the **+Add** button in the Content Browser. [image: Click the Add button in the Content Browser]

- **Font Editor** window appears. [image: Font Editor window]

- Click the **Add Font** button to add a new font selection to the **Default Font Family**. [image: Click the Add Font button]

- Select the **folder** button next to the selection dropdown. [image: Select the **folder** button]

- After the **Import** dialog box appears, navigate to the `TFF` or `OTF` font file you want to import and select it. Then, click **Open**. [image: Select Font in the Import dialog window]

- Next, the **Save Font Face** window will appear. Give your font a name and choose the save location in your game folder's hierarchy. Then, click **Save**. [image: The Save Font Face window]

- The Font Face asset can now be found in your folder hierarchy. [image: The imported Font Face asset in folder]
