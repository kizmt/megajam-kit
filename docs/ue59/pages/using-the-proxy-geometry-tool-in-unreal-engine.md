# Using the Proxy Geometry Tool

https://dev.epicgames.com/documentation/en-us/unreal-engine/using-the-proxy-geometry-tool-in-unreal-engine?application_version=5.9

> In the following How - To we will take a look at how you go about using the Proxy Geometry Tool in your UE5 projects.

[image: Using the Proxy Geometry Tool]

In the following How - To we will take a look at using the Proxy Geometry Tool to create new Static Meshes and Textures for your UE5 projects levels.

## Steps

- The **Proxy Geometry Tools** are part of the Merge Actor tools so to open them up you need to go to **Tools** and then click on the **Merge Actors** option.[image: Merge Actors tool] Click image for full size.
- When the Merge Actors tool is open, you should see two icons at the top. Click on the second icon to show the options for the Proxy Geometry Tools. [image: Merge Actors tool] Click image for full size. The options in the Proxy Geometry tool will only become active when you have Static Meshes selected in a level.
- Navigate to a location in a level and then start selecting Static Meshes. For this example 21 Static Meshes have been selected but please feel free to select as many Static Meshes as you want.[image: Selecting Static Meshes] Click image for full size.
- With the Static Meshes still selected locate the Merge Actors window and then press the **Merge Actors** button to begin the Proxy Geometry tool creation process.[image: Merge Actors button] Click image for full size.
- When prompted, specify a **Name** and **Location** for the new assets that the Proxy Geometry Tool will create. Once that is completed, press the **Save** button to continue the Proxy Geometry tool creation process.[image: Creating Static Mesh] Click image for full size. The time that it takes for the Proxy Geometry tool to finish can range from a few minutes to a few hours. The current progress will be shown in the following window.[image: Creating Mesh Proxy] Click image for full size.
- When the Proxy Geometry tool has completed, go to the Content Browser and search for the newly created assets by input the name given to them in step five.[image: Newly Created Static Mesh] Click image for full size.

## End Result

To view the Static Mesh that was created, go to the Content Browser and double-click on the Static Mesh that was generated. When looking at the Static Mesh in the Static Mesh Editor, note the reduced triangle and material count.
