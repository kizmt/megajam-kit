# Consoles

https://dev.epicgames.com/documentation/en-us/unreal-engine/consoles-development-in-unreal-engine?application_version=5.9

> Get started developing for consoles with Unreal Engine.

Unreal Engine supports development for all the major games consoles. To get started with development, refer to the appropriate page for that consoles and follow the instructions to register as a developer and get set up.

- Nintendo Switch (-> development-for-nintendo-switch-in-unreal-engine): Get started developing for Nintendo Switch with Unreal Engine.

- Nintendo Switch 2 (-> nintendo-switch-2): Get started developing for Nintendo Switch 2 with Unreal Engine.

- PlayStation 4 (-> development-for-playstation-4-in-unreal-engine): Get started developing for Sony PlayStation 4 with Unreal Engine.

- PlayStation 5 (-> development-for-playstation-5-in-unreal-engine): Get started developing for Sony PlayStation 5 with Unreal Engine.

- Xbox (-> xbox-development-in-unreal-engine): Get started developing for Xbox with Unreal Engine.
