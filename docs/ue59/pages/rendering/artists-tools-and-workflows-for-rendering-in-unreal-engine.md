# Artists Tools and Workflows for Rendering

https://dev.epicgames.com/documentation/en-us/unreal-engine/artists-tools-and-workflows-for-rendering-in-unreal-engine?application_version=5.9

> A collection of tools and workflows artists can use to create content, such as texture-animated objects, in-editor texture creation tools, compositing materials, and more.

Unreal Engine contains some in-editor tools and provides some for DCC applications to aid in content creation. Generally, these tools have been developed with specific intention and by technical artists with specific purposes in mind.

The tools and workflows listed in this page will help with creating content or achieving some goal for your own projects.

## Rendering Tools for Artists

The tools in this section are useful for those creating content from within the Unreal Editor and for those using specified DCC Applications.

- Impostor Baker Plugin (-> impostor-baker-plugin-in-unreal-engine): A tool to bake out simplified representations of complex geometry for use in far-distance rendering as level of detail meshes.

- Pivot Painter Tool (-> pivot-painter-tool-in-unreal-engine): A landing page for the Pivot Painter Tool

- Pivot Painter Tool 2.0 (-> pivot-painter-tool-2.0-in-unreal-engine): Guide to the Pivot Painter 2.0 MAXScript, which stores model pivot and rotation data within vertices for interactive animation.

- Doodle (-> doodle-in-unreal-engine): Draw 2D notes over editor viewports and save or share them with Doodle.
