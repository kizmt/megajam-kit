# Create Automation Tests

https://dev.epicgames.com/documentation/en-us/unreal-engine/create-automation-tests-in-unreal-engine?application_version=5.9

> A collection of topics related to creating automation tests.

- Write C++ Tests (-> write-cplusplus-tests-in-unreal-engine): Programmer's guide to creating engine-level Automation Tests.

- Automation Driver (-> automation-driver-in-unreal-engine): An overview of the new Automation Driver feature, which enables programmers to simulate user input.

- Automation Spec (-> automation-spec-in-unreal-engine): Overview covering a new type of automation test, known as a 'Spec', which has been added to our existing automation testing framework.

- Functional Testing (-> functional-testing-in-unreal-engine): Framework for Functional Testing.

- Screenshot Comparison Tool (-> screenshot-comparison-tool-in-unreal-engine): An overview of creating and comparing screenshots using the Automation System in Unreal Engine.

- Write Editor Tests with Utility Blueprints (-> write-editor-tests-with-utility-blueprints-in-unreal-engine): Learn how to create Editor Tests with Blueprint.

- Write Editor Tests with Python (-> write-editor-tests-with-python-in-unreal-engine): Learn how to create Editor Tests with Python.

- FBX Test Builder (-> fbx-test-builder-in-unreal-engine): The FBX Automation Test Builder enables you to create tests for FBX files to be used with the Session Frontend for Automation Testing.
