# Playback in Chaos Visual Debugger

https://dev.epicgames.com/documentation/en-us/unreal-engine/playback-in-chaos-visual-debugger?application_version=5.9

> Play back recordings in Chaos Visual Debugger.

[image: Playback in Chaos Visual Debugger]

**Chaos Visual Debugger (-> chaos-visual-debugger-in-unreal-engine)** (**CVD**) saves recordings as two types of files:

- `.utrace` (Generated by saving a single-source recording.)
- `.cvdmulti` (Generated by combining multiple `.utrace` files.)

On this page, you’ll learn how to locate and load `.utrace` and `.cvdmulti` files into CVD for:

- Single-Source Recordings (-> playback-in-chaos-visual-debugger)
- Multi-Source Recordings (-> playback-in-chaos-visual-debugger)

## Load Single-Source Recordings

[image: Single-Source Recording]

CVD stores `.utrace` files in different locations on disk depending on how they were recorded and what type of application was recorded:

| Application Type | Location on Disk | Example |
| --- | --- | --- |
| PIE sessionGame clientGame server | Inside the project folder. For example:`[ProjectFolder]/Saved/Profiling` | [image: PIE Session File Path] |
| Packaged build | Inside the project's build folder. For example:`[BuildFolder]/[Platform]/Saved/Profiling` | [image: Packaged Build File Path] |
| Live recording | Inside the Unreal Trace Folder. For example:`UnrealEngine/Common/UnrealTrace/Store/001/` | [image: Live Recording File Path] |

### Load a UTRACE File

To load a recording follow these steps:

- In the main toolbar of CVD, click **Open File**. [image: Open File]
- In the **Open CVD file** dialog, **Loading Mode **is set to **Single Source **by default, so you don’t need to change this option. From the **Folder **dropdown menu, select the folder your recording is stored in. Click **Open Folder**.[image: Open CVD File]
- Select the `.utrace` file you want to load and click **Open**.

## Load Multi-Source Recordings

[image: Multi-Source Recording]

### Load Multiple UTRACE Files

Loading multiple single-source recordings is the first step to creating a CVDMULTI file. However, this can also be useful for visualizing two single-source recordings simultaneously to inspect for discrepancies.

To load multiple `.utrace` files, follow these steps:

- In the main toolbar of CVD, click Open File. [image: Open File]
- In the **Open CVD file** dialog, in the Loading Mode dropdown, select **Multi-Source.**[image: Open CVD File Muti Source]
- From the **Folder **dropdown menu, select the folder that contains your recording. Click **Open Folder**.[image: Open CVD File]
- Select the `.utrace` files you want to load and click **Open**. CVD automatically loads both files.

### Create a CVDMULTI File

Once two `.utrace` files are loaded into CVD, the **Combine **button becomes available in the main toolbar. Click **Combine **and save the new `.cvdmulti` file at your preferred destination.

[image: Combine Button]

### Load a CVDMULTI File

To load a `.cdmulti` file, follow these steps:

- In the main toolbar of CVD, click **Open File**. [image: Open File]
- In the **Open CVD file** dialog, verify that the **Loading Mode** is set to **Single Source**. From the **Folder **dropdown menu, select the folder that contains your recording. Click **Open Folder**.[image: Open CVD File]
- Select the `.cvdmulti` file you want to load and click **Open**.

There is a known issue where the first frame will not automatically play after the file loads. Geometry will not generate until you click the **Play **icon in the **Game Frames Timeline**.

[image: Game Frames Timeline Play]
