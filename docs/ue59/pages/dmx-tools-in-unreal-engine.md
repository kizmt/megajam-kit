# DMX Tools

https://dev.epicgames.com/documentation/en-us/unreal-engine/dmx-tools-in-unreal-engine?application_version=5.9

> Use the DMX tools to control live events and digital installations.

[image: DMX Tools]

Unreal Engine provides a variety of powerful tools to help you control your DMX installations, for both live and digital installations. Refer to the documentation listed below for more information on how to use these tools and integrate them into your DMX project.

- [image: DMX Activity and Channel Monitors] DMX Activity and Channel MonitorsUse the DMX Activity and Channel Monitors to track your DMX installations. (-> dmx-activity-and-channel-monitors-in-unreal-engine)
- [image: DMX Conflict Monitor] DMX Conflict MonitorInformation about the DMX Conflict Monitor, which checks for potential data collisions between DMX tools in Unreal Engine. (-> dmx-data-conflict-monitoring-in-unreal-engine)
- [image: DMX Control Console] DMX Control ConsoleUse the Control Console to control your fixtures using your library and patch selection. (-> dmx-control-console)
- [image: DMX Patch Tool] DMX Patch ToolUse the DMX Patch Tool to quickly apply DMX Libraries and Patches. (-> dmx-patch-tool-in-unreal-engine)
