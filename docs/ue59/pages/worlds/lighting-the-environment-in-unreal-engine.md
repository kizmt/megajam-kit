# Lighting the Environment

https://dev.epicgames.com/documentation/en-us/unreal-engine/lighting-the-environment-in-unreal-engine?application_version=5.9

> Topics that demonstrate features and tools for lighting scenes.

[image: Lighting the Environment]

A significant part of building any virtual world is determining how it will be lit. This means being able to efficiently light small enclosed scenes with small lights to large worlds primarily lit by a single dominant light source. The engine provides the tools and lighting options necessary to achieve the results your project demands.

The topics in this page contain information on the various lighting features and tools available to use, along with guides that create a learning path to the ins and outs of lighting a scene in Unreal Engine.
