Module 6 Overview

In this module, we will show you how to add another layer of gameplay to your level by creating checkpoints and kill volumes using Blueprints. The checkpoint system keeps the player from having to restart the whole level each time they fall. The kill volumes will teleport the player back to the start or a checkpoint if they fall and touch them.

### Creating the Kill Volume

The kill volumes teleport the player back to the start or a checkpoint when they are touched

### Building the Level Checkpoint

Level checkpoints keep the player from going all the way back to the start
