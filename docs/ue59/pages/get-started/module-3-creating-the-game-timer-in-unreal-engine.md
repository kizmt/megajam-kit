Module 3 Overview

In this module, we will show you how to create a game timer that counts down and gives your players a sense of urgency as they run through your level. You will learn how to track the time in Blueprint, and convert the time to a minutes and seconds format. Then you will build a user interface widget to display the timer on the screen.
