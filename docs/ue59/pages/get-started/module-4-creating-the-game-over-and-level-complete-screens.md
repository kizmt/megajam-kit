Module 4 Overview

In this module, we will show how to create win and loss states using Game Over and Level Complete screens using Unreal Motion Graphics (UMG). You will learn how to program the buttons in these widgets to restart and quit your game, as well as load other levels. You will learn to trigger these states so that the correct screen appears when the player runs out of time or crosses the finish line.
