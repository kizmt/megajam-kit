# Unreal Editor Scripting Tutorials

https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-editor-scripting-tutorials?application_version=5.9

> Provides a list of example pages that show how to use Blueprints and Python to script and automate content production tasks in the Unreal Editor.

The pages in this section show you how to use Blueprints and Python to automate some common content production tasks in the Unreal Editor. You can copy these examples directly, or use them as models for your own scripts.

## Scripting Tutorials

- Creating Levels of Detail in Blueprints and Python (-> creating-levels-of-detail-in-blueprints-and-python-in-unreal-engine): Shows how to set up automatic Levels of Detail (LODs) in the Unreal Editor using Blueprints and Python.

- Setting up Collisions with Static Meshes in Blueprints and Python (-> setting-up-collisions-with-static-meshes-in-blueprints-and-python-in-unreal-engine): Describes how to set up collision properties for a Static Mesh in the Unreal Editor using Blueprints or Python.
