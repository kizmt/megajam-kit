> Different methods to create and setup input in Unreal Engine

[image: Input]

The **Player Input** object is responsible for converting input from the player into data that actors (like player controllers or pawns)
can understand and use. It is part of an input processing flow that translates hardware input from players into game events and movement with Player Input mappings and Input components.

You can get started with the Input Overview (-> input-overview-in-unreal-engine) or choose any of the topics below.
