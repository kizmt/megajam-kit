# Blueprint User Interface Components

https://dev.epicgames.com/documentation/en-us/unreal-engine/user-interface-components-in-unreal-engine?application_version=5.9

> Outlines the Blueprint Editor's Interface components and its basic usage instructions.

## User Interface Components Breakdown

Below you will find a User Interface for the specific components of the Blueprint Editor.

## Topics

- Blueprint Editor Compiler Results (-> compiler-results-in-the-blueprints-visual-scripting-editor-for-unreal-engine): Interface for the Compiler Results panel of the Blueprint Editor.

- Blueprint Editor Debug Panel (-> debug-panel-in-the-blueprints-visual-scripting-editor-for-unreal-engine): Panel that provides a list of all debug tools currently in use for the Blueprint.

- Blueprint Editor Details Panel (-> details-panel-in-the-blueprints-visual-scriting-editor-for-unreal-engine): Overview of the Details panel within the Blueprint Editor.

- Blueprint Editor Find Result Panel (-> find-result-panel-in-the-blueprints-visual-scripting-editor-for-unreal-engine): Panel that is a search tool within the Blueprint Editor that allows you to quickly track down a variety of objects.

- Blueprint Editor Graph Editor (-> graph-editor-for-the-blueprints-visual-scripting-editor-in-unreal-engine): Editable, visual representation of a network of nodes within a Blueprint.

- Blueprint Editor Menu (-> menu-for-the-blueprints-visual-scripting-editor-in-unreal-engine): Menu that is used to do multiple actions, such as saving, loading and opening windows.

- Blueprint Editor My Blueprint Panel (-> my-blueprint-panel-in-the-blueprints-visual-scripting-editor-for-unreal-engine): Hierarchical breakdown of the nodes within a Blueprint.

- Blueprint Editor Palette (-> palette-in-the-bleprints-visual-scripting-editor-for-unreal-engine): Non-context sensitive listing of all functions and variables for Palette that can be used in Blueprints.

- Blueprint Editor Toolbar (-> toolbar-in-the-blueprints-visual-scripting-editor-for-unreal-engine): A bar at the top of the editor that contains buttons that control multiple functions.

- Blueprint Editor Viewport (-> components-mode-viewport-in-the-blueprints-visual-scripting-editor-for-unreal-engine): Overview of the viewport in the Components mode of Blueprint Classes
