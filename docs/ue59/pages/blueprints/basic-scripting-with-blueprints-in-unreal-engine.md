# Basic Scripting with Blueprints

https://dev.epicgames.com/documentation/en-us/unreal-engine/basic-scripting-with-blueprints-in-unreal-engine?application_version=5.9

> Get a general overview of the variables and execution flow of the Blueprints visual scripting system.

[image: Basic Scripting with Blueprints]

Blueprints provide a visual approach to a scripting language. As such, the system shares many of the nuances of a standard written scripting language, such as data typed variables, arrays, structs, etc. Execution flow also works as it does in a typical scripting language, although Blueprints require explicit linear execution for each node. Each of the pages below go into more detail about different variable types, working with those variables, and execution of nodes within the graph.

- [image: Connecting Nodes] Connecting NodesExamples of the ways to connect nodes together in Blueprints. (-> connecting-nodes-in-unreal-engine)

- [image: Events] EventsNodes that are called from gameplay code to begin execution of an individual network within the EventGraph. (-> events-in-unreal-engine)
- [image: Flow Control] Flow ControlNodes that allow for controlling the flow of execution based on conditions. (-> flow-control-in-unreal-engine)
- [image: Nodes] NodesNode graph that uses events and function calls to perform actions in response to gameplay events associated with the Blueprint. (-> nodes-in-unreal-engine)

- [image: Custom Events] Custom EventsCustom user-created events that can be fired off from within a Graph. (-> custom-events-in-unreal-engine)
